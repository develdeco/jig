# D10: the recorded gate, the review verbs and the publish forms

Branch `dg/D10`, from the `digester` tip 4e8e648 (S0b, S0a, D6 merged), then
merged with bdd8129 (D7, D8, D15, D17 landed). jig launches no model in the
gate or in publish. `jig gate` opens a round and starts no reviewer; an agent
that jig did not start (a subagent or another session, with a fresh context)
reads the round with `jig review context`, reports with `jig finding` and
`jig review done`, and the round is recorded when that call returns. Publish
has four forms and reconciles, squashes, memorizes and commits nothing on the
branch. `jig run` and its build steps are untouched (D13 removes them).

## Verbs

```
jig gate [T] [--early] [--branch B] [--intent TEXT | --doc FILE] [--yes] [--store P] [--project N]
         hidden: --scenario DIR
jig review context [T] [--session ID] [--model M] [--effort E] [--json] [--store P] [--project N]   (Order 330)
jig finding [T] --file F --line N --title T --detail D --action fix|ask|note --risk low|medium|high
            --risk-rationale R [--oracle O] [--prior ID]                          (Order 331)
jig finding [T] --still-present ID [--line N]
jig review done [T] (--result FILE | --reviewed PATHS --summary TEXT) [--session ID] (Order 332)
jig triage T ID keep|dismiss [--reason TEXT] [--workspace W] [--oracle O]           (Order 333)
jig publish [T] [--yes] [--repo R] [--picks FILE]       bare: push the reviewed head, open or update the PR
jig publish [T] --body [--picks FILE]                   render the PR body and review notes, change nothing else
jig publish [T] --pr URL                                record a PR somebody else opened
jig publish [T] --approve                               record an approval of the reviewed head
```

- **gate** keeps `--branch`, `--intent`, `--doc`, `--early`, `--yes`; `--backend` and the
  unimplemented `--pr` placeholder are gone; the hidden `--scenario` stays for tests (it drives the
  legacy `Gate` with a scripted source). It prints the open round (a `review` table: ticket, round,
  branch, copy, head, base, scope, worktree, request, intent, must_review) plus a help line. It
  starts nothing. `--yes` is stored in the open record and used by the round's triage. A round
  whose frontier is short of green is refused as before (`GATE_NOT_GREEN`, help names `jig next`).
- **review context** prints the open round (opening it with the gate's defaults when none is open)
  and the tables a reviewer reads: `must_review`, `open`, `dismissed`, `oracles_passed`. `--json`
  prints the whole request. `--session` or `$JIG_SESSION`, `--model` and `--effort` are recorded in
  the open record as what the reviewer says of itself.
- **finding** appends one draft to `work/gate.round-N.findings.ndjson`, held to the rules of a
  result finding (line, action, risk, oracle named when the manifest has more than one). It prints
  the id the finding will have. `--still-present` confirms an earlier finding unchanged.
- **review done** reads the drafts (or `--result`), checks the report like any reviewer report
  (`REVIEW_INVALID` leaves the round open) and records the round (`GateFinish`).
  `REVIEW_STALE_HEAD`: the branch moved, run `jig gate` again. `REVIEW_NOT_OPEN`: nothing to close.
  `REVIEW_NOT_INDEPENDENT`: the reviewer built part of the change; the round is recorded with
  verdict `not-independent` and the verb exits 1.
- **triage** (kept, its prompts removed): records `keep` or `dismiss` for an ask; a person at a
  terminal is recorded as `person`, anything else as `agent`. The next `jig gate` round applies
  what was decided; an ask nobody decided stays undecided (no prompt, no default unless
  `gate --yes`).
- **publish** forms are mutually exclusive. Bare publish pushes the reviewed head unchanged and
  asks first (`PUBLISH_DECLINED` when stdin is not a terminal; `--yes` or a person's recorded
  approval of that head stands in). `--body` writes `pr/<repo>.md` and the review notes and
  journals `pr-body`. `--pr URL` checks, when the repo has a host, that the PR is from the
  ticket's branch (`PR_HEAD_MISMATCH`) and at the reviewed head (`PUBLISH_UNREVIEWED_HEAD`), then
  journals `pr` and `publish-done`; with no host it records the URL unverified and warns.
  `--approve` journals `publish-approved`. `--picks FILE` is a picks file (`ParsePicksResult`
  shape); with recordings to pick and no file, `--body` and bare publish print `picks: pending`
  and write a `picks.json` request instead of dispatching a session.
- `jig here` gains a `publish` section (Order 330): the open round, the latest round's verdict and
  independence, and the body, approval and PR the journal holds.
- Skills `skills/review` and `skills/publish` (lint-clean) teach both flows.

## Where the work is

- **The copy reviewed** is chosen by `pointAtBranchCopy` (adopt.go): the operator clone's committed
  branch (fetched into the gate lease) against origin's, by `pool.Compare`; a diverged pair is
  `BRANCH_DIVERGED` naming the clone, no copy is `BRANCH_NOT_FOUND`. The clone's working tree is
  never read: the reviewer reads the gate lease, a pristine checkout of the head. A ticket `jig
  run` built still falls back to its build lease (not for an adopted branch). Publish ships the same
  copy and refuses a head that is not the reviewed one.
- **The open round** lives in the store's `work/`, committed and pushed:
  `gate.round-N.review.json` (the request), `gate.round-N.open.yaml`,
  `gate.round-N.findings.ndjson` (drafts), `gate.round-N.result.json` (what `review done`
  recorded). There is no `gate/round-N` directory before `done`; `existingGateRounds` counts only
  `gate/round-*`. Reopening a round whose head has not moved keeps the drafts and the reviewer's
  self-report; a moved head starts again.
- **Privacy:** nothing committed to the store names the jig home. The open record keeps the lease,
  the intent excerpt, the recordings list and the reviewer's request as paths relative to the jig
  home; the store's `review.json` has the worktree, excerpt and recordings paths cleared. The
  reviewer's whole request is a file under the jig home (`home.ReviewDir`, `review.json` beside
  `recordings.json`): it is the `request:` row of `jig review context`, and `--json` prints it.
  A launched reviewer (the legacy `Gate`) reads that copy only when its request carries an intent
  excerpt; otherwise it reads the store's file as before.
- **Independence:** builders are (session, agent) pairs from journal `claim`, `verify-pending` and
  `oracle` lines and from ledger `git-commit` and tool lines naming files. The reviewer is, in
  order: the `--session` flag, `$JIG_SESSION`, the session recorded in the open record, a ledger
  tool line running `jig review context <T>`. A reviewer that is a builder gives verdict
  `not-independent` and `REVIEW_NOT_INDEPENDENT`, with the round still recorded; an unknown
  reviewer gives `independent: unknown`, which publish accepts. Publish refuses `not-independent`
  (`PUBLISH_NOT_INDEPENDENT`) and an unclean round (`PUBLISH_NOT_CLEAN`).
- **Triage** is read at the next round (`recordedTriage`): journal `triage` lines decide asks;
  `gate --yes` (stored in the open record) falls back to the default decisions; anything else
  stays undecided.

## Line shapes

| Where | Line |
|---|---|
| journal `gate-open` | as before, written when the round opens |
| journal `gate-round` / `gate-clean` | `Attempt` = round, plus `Session`, `Agent`, `Model`, `Effort` of the reviewer |
| journal `triage` | `Ref` finding id, `Outcome` keep or dismiss, `Summary` reason, `Command` `workspace=W oracle=O`, `Provenance` person or agent, `Session` |
| journal `pr-body` | `Commit` reviewed head, `Branch`, `Ref` store-relative path of `pr/<repo>.md` |
| journal `publish-approved` | `Commit` head, `Branch`, `Provenance` person or agent |
| journal `pr` | `URL`, `Branch`, `Commit`, `Outcome` opened, updated, recorded, `recorded:unverified` or `none:no-host` |
| journal `changelog`, `publish-done` | written after the push or the record: changelogs, ledger entry, contract index and evidence are written then, not before |
| `gate/round-N/report.yaml` | adds `independent` (plain `true`, `false` or `unknown`), `reviewer` (session, agent, how), `effort`, `oracle_names` |
| report rows | `copy`, `model`, `effort`, `reviewer`, `independent` |

Publish tier is always `none`; the `reconcile`, `revalidate`, `memorize` and `squash` journal lines
are never written. The reconcile code (`reconcile.go`) and its tests are deleted.

## Deviations

- `internal/spawn/spawn_windows.go`: detached children are now started with `CREATE_NO_WINDOW`
  instead of `DETACHED_PROCESS`. A child with no console at all makes Windows allocate a console
  window for every console program it starts (every `git` a verification worker runs), which flashes
  windows on screen and does not return while the session is locked: every verification worker hung
  in `git rev-parse` and no e2e test could finish. The child keeps its own process group and job
  breakaway. This is outside D10's brief; it was needed to run the named e2e tests, and it made them
  an order of magnitude faster (the four named tests: about 17 s together, from several minutes).
- `PrepareReviewRequest` writes the reviewer a second copy of the request under the jig home (see
  Privacy), because the store's file may not name the jig home.
- `e2e/gate_recorded_test.go`'s `newBuiltTicket` fails at once, with the oracle's summary, when a
  slice's oracle fails, instead of waiting out the timeout.
- Pre-existing and not touched: `TestHarnessWaitVerifiers` (S0's harness test) failed once in a
  full-suite run, "still running 400ms after" for a worker that had exited (a reused pid under
  load); it passes alone and in two further full runs.
- `jig run`'s build steps keep using `Gate` through the legacy driver until D13.

## ADR impact

- ADR 0012 (intent provenance) and 0014 (demo session at the gate): the gate no longer summarizes
  an intent or runs a demo session; the reviewer is pointed at an excerpt of the author's session,
  and the pull request's demo is the agent's pick from a request jig writes (`--picks`).
- 0007 (the reviewer owns bookkeeping, not judgment) still holds; the reviewer is now an agent jig
  did not start.
- A new ADR (D1's to write): the gate is recorded, not launched - independence by provenance, the
  open round in the store, publish ships the reviewed head unchanged.
