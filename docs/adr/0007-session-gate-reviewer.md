# Session-dispatched gate reviewer

`jig gate` now dispatches a real reviewer session instead of only re-running oracles: the reviewer reads `review.json` (the brief, slices and journal paths, the prior round's open findings, and every cumulative dismissal), reviews the ticket branch's diff against the brief without editing anything, and writes `result.json` with classified findings. Findings split into two classes: mechanical (typo, dead code, doc gap, formatting) bundles into one fix slice per workspace, pinned to the cheapest staircase rung, since fixing a typo needs no escalation; intent (behavior, correctness, security, design) becomes its own fix slice at the gate's own model. A human, or `--yes`, triages the open findings before any slice is synthesized - review has no back edges, so a finding is either dismissed for good or becomes forward work, never a comment left sitting outside the frontier.

Rounds are incremental: round 1 reviews the full diff against the ticket's start point, and once a round's `reviewed_sha` is a real ancestor of the next round's HEAD, that next round reviews only the delta since it, closing or re-raising each prior open finding by id. Anything that breaks that anchor - a missing prior round, a rebase, an unrelated repo - falls back to a full review rather than trusting a stale or unrelated base. A dismissed finding's normalized title (lowercased, whitespace collapsed) is checked against every later round's findings automatically, so a dismissal cannot resurface even if the reviewer raises it again in different words.

The reviewer session is held to the same forward-only discipline as the rest of jig: after dispatch, jig checks the lease's HEAD and `git status` are unchanged from before dispatch and rejects the round outright if the reviewer touched anything - reviewers never edit. `result.json` is parsed strictly (exactly one JSON object, a known verdict, non-empty titles, valid classes, closures naming only real prior findings) so a malformed or off-contract session result fails loudly instead of silently becoming "clean".
