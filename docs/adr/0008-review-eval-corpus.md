# Review-quality eval corpus

Review quality is a measured artifact, not a vibe: `internal/revieweval` runs the gate reviewer's exact prompt template and strict result parser (`RenderReviewPrompt`, `ParseReviewResult` - no logic duplicated) against a labeled corpus under `testdata/revieweval/<case>/`. A case is a creation-only diff (`patch.diff`, applied to an empty base commit so every file under review is new), a `brief.md`, a `review.json` request template, and a `gold.yaml` of findings that must be found (id, class, a title regexp, a file) and traps that must not be flagged - correct-but-unusual code shaped to tempt a false positive. A case passes iff every gold finding is matched and nothing matches a trap (or, for a case with no gold findings at all, nothing is flagged); other findings are reported as unmatched without failing the case, since reviewer creativity beyond the gold set is not itself a bug.

CI runs only the structural path: a fake backend replays scripted `result.json` fixtures, both a perfect result (every case should PASS) and a regressed one with a seeded miss, false positive, or misclassification (every case should FAIL with the exact expected counts) - proof the scorer itself can fail, not just pass. The live path (`JIG_REVIEWEVAL_BACKEND=headless go test ./internal/revieweval -run Eval`, model from `JIG_REVIEWEVAL_MODEL`, report written to `JIG_REVIEWEVAL_REPORT` when set) drives a real backend and is report-only: a case's pass or fail is a measurement, and only infrastructure failure (an unavailable backend, a corpus that will not load) fails the test.

Growth is capture, not new machinery: every real gate round already persists its `review.json` and `result.json` in the store, so a future corpus case is pulled from a real round plus a hand-written `gold.yaml`, not built from scratch. Deferred out of this run: tracking which findings a human later found were CI misses (a bug the reviewer missed that a subsequent CI run caught), and CI-after-PR monitoring more broadly - both need a place to record ground truth after the PR merges, which this run's disk-only, foreground pipeline does not yet have.
