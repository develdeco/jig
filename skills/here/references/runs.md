**A start-to-finish run** is a prompt that names several phases ("Take SHOP-1 from brief to PR"): run them in order, each with its skill, without waiting for a prompt to start the next, and end the run at a refusal or a stop the skill gives. Wait for the review's reviewer as `jig gate` says (a subagent hands back with the round open); never schedule a wakeup or stall. Such a run hands over no decision: the brief's questions and approval, a review's asks and the publish approval stay the person's, so ask and wait. **Recommendations** are a separate hand-over: a prompt that tells you to go with your recommendations lets you answer those decisions yourself, recorded as yours (a brief approval with agent provenance, a publish the publish skill's first way, which asks for no approval). A prompt can ask for either or both.

**A chart run** is a prompt aimed at a chart: "Take <chart> to PR" (nothing started), "Continue <chart>" (started), or a yes to the verdict's question. A prompt naming several tickets of one chart ("Take A and B to PR") is a chart run over those only; tickets of no chart, or of two, are ticket runs: say so. `jig next <chart>` gives its standing and the prompt; run it with the chart skill (`jig skill chart`). `jig next` lists the charts.

When `jig next` ends with an `overlap` table, two tickets' local branches change the same file: build them one after the other.
